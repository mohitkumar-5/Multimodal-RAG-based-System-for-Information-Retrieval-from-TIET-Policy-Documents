Security & Scope

Our Document Library

PolicyLens references an exhaustive set of 100+ primary source documents from Thapar Institute of Engineering and Technology (TIET). This includes tuition fee circulars, PG/UG prospectus schedules, course catalogs, credit lists, and Hostel rules.

Every response generated is explicitly cross-referenced. If information cannot be verified directly in the database, the system alerts you and cites its source files to prevent errors.

Privacy Commitment

We prioritize your academic data security. Your conversation history is handled through clean Redis-capped namespaces and falls back to browser-localized memory sessions if needed.

We use secure Serverless router pipelines to handle LLM fallbacks, ensuring that queries are processed directly and never stored by external APIs.
